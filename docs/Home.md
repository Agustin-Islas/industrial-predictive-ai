#  Plataforma de Mantenimiento Predictivo Industrial

Bienvenidos a la documentación central del proyecto. Este repositorio implementa una solución de mantenimiento predictivo utilizando inteligencia artificial, orientada a la industria petroquímica (ej. YPF).

## ️ Mapa del Proyecto

- [[Architecture]] - Detalle de las 3 capas de inteligencia y la infraestructura.
- [[Datasets]] - Información sobre los datos de AI4I y NASA C-MAPSS.
- [[Models]] - Descripción de los modelos de Machine Learning utilizados.

##  Inicio Rápido

El proyecto se divide en 4 módulos principales:
1. `notebooks/`: Entornos de experimentación y EDA.
2. `models/`: Modelos entrenados exportados (.pkl, .pt).
3. `backend/`: API RESTful y WebSockets (FastAPI).
4. `frontend/`: Dashboard de visualización en tiempo real (Next.js).
